# Closing changed work

Adapted from AGCoord's contributor workflow. Work that changes code, documentation,
tickets or packaging ends with these four sections in order; omit genuinely empty
sections. Read-only answers do not need a handoff.

1. **What I did.** State concrete changes, branch, issue descriptions and merge status.
   Report failed or skipped validation plainly.
2. **What is open.** List unfinished work, review or landing and validation not run.
   Every issue number includes a sentence explaining the work it tracks.
3. **Decisions needed.** Include only material decisions belonging to the reader.
   Make routine implementation choices yourself.
4. **Options and recommendation.** For each decision, state choices, cost and a recommendation.

Keep durable design reasoning in canonical docs and link to it from the handoff.
