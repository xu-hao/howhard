# Project image provenance

## Spiral mark

[spiral.png](spiral.png) is howhard's project mark, published in the repository
README and documentation homepage. It is a simple round black spiral with smooth,
evenly spaced lines and rounded ends. The plain white presentation background keeps
it legible in both light and dark interfaces.

The image was generated with OpenAI's image generation tool on 2026-11-14 for this
project, following the user's selected spiral concept. The final brief requested
clean abstract monochrome lines with no cartoon styling, shading, gradients, maze
junctions or decorative elements. No third-party source image was used. The
generated PNG is copied unchanged into this directory.

The asset is 1254 by 1254 pixels. Its SHA-256 checksum is
`ce018b554c6a38c3a67acf0e836ce404ccb1438093d4c36470e4f60f4fb19635`.

The user's publication instruction is tracked by
[issue #87](https://github.com/xu-hao/howhard/issues/87), which covers publishing
the approved spiral in the README and documentation.
